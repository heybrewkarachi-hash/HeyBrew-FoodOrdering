## Required sizes

| Surface | Display size | Export / upload size | Aspect |
|---------|--------------|----------------------|--------|
| Desktop | **1440 × 320** px | **2880 × 640** px (2×) | 9∶2 |
| Mobile | **900 × 450** px | **900 × 450** px (or 1800 × 900 @2×) | 2∶1 |

- Desktop crop is wide and short (mockup). Keep cups and headline readable on the left.
- Mobile is a separate crop so text and cups are not cut off on phones.
- Store on Cloudinary; set `imageUrl` (desktop) and `imageUrlMobile` in admin / store settings.

Temporary demo images use Unsplash crops at these ratios — replace before production.
